# Russian Learning Track

## Goal
Learn Russian from basics to professional/technical level.

## Structure

- `vocabulary.md` — Words and phrases organized by topic
- `grammar.md` — Grammar rules, cases, verb conjugation
- `practice.md` — Exercises and sentences to practice
- `technical.md` — Technical/IT vocabulary in Russian

## Levels
1. **Basics** — Alphabet, pronunciation, basic phrases, numbers
2. **Conversational** — Daily situations, common expressions, questions
3. **Professional** — Work communication, meetings, technical discussions
