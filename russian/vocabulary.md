# Russian Vocabulary (Словарный запас)

## Verbs — Imperfective / Perfective Pairs

| Imperfective | Perfective | English | Work Example |
|---|---|---|---|
| делать | сделать | to do | Я **сделаю** это сегодня |
| писать | написать | to write | **Напиши** в Слаке |
| исправлять | исправить | to fix | Я **исправлю** этот баг |
| обсуждать | обсудить | to discuss | Давай **обсудим** на созвоне |
| проверять | проверить | to check/review | **Проверь** мой ПР |
| отправлять | отправить | to send | **Отправь** мне ссылку |
| смотреть | посмотреть | to look at | **Посмотри** этот код |

## Work Phrases (Рабочие фразы)

| Russian | Transliteration | English |
|---|---|---|
| Можешь посмотреть мой ПР? | Mozhesh posmotret moy PR? | Can you review my PR? |
| Я завтра исправлю этот баг | Ya zavtra ispravlyu etot bag | I'll fix this bug tomorrow |
| У меня есть вопрос | U menya yest vopros | I have a question |
| Давай обсудим это на дейлике | Davay obsudim eto na deylike | Let's discuss this on the daily |
| Я не уверен в архитектуре | Ya ne uveren v arkhitekture | I'm not sure about the architecture |

## Nouns — Gender Guide

| Masculine (-consonant) | Feminine (-а, -я) | Neuter (-о, -е) |
|---|---|---|
| баг (bug) | задача (task) | приложение (app) |
| сервер (server) | ветка (branch) | ревью (review) |
| проект (project) | база (database) | обновление (update) |
| код (code) | ошибка (error) | сообщение (message) |
| тест (test) | фича (feature) | поле (field) |
| деплой (deploy) | таблица (table) | значение (value) |
