## Phase 1: Core Grammar (Ядро грамматики)

### 1.1 Cases (Падежи) ⬜
The #1 priority. Cases change word endings based on the role in the sentence.

**6 cases to learn:**

| # | Case | Question | Example | When used |
|---|------|----------|---------|-----------|
| 1 | Именительный (Nominative) | Кто? Что? | Это **программист** | Subject — who/what does the action |
| 2 | Родительный (Genitive) | Кого? Чего? | Нет **программиста** | Possession, absence, "of something" |
| 3 | Дательный (Dative) | Кому? Чему? | Отправь **программисту** | To whom, for whom |
| 4 | Винительный (Accusative) | Кого? Что? | Вижу **программиста** | Direct object — what you act on |
| 5 | Творительный (Instrumental) | Кем? Чем? | Работаю **программистом** | With what, by means of, "as" |
| 6 | Предложный (Prepositional) | О ком? О чём? | Говорю о **программисте** | About, in, at (always with a preposition) |

**Learning order (by usefulness):**
- [x] Именительный — already know (basic form)
- [x] Винительный — most common, direct objects ("я вижу задачу")
- [x] Предложный — location, topic ("в офисе", "о проекте")
- [x] Родительный — "нет чего", possession ("код сервера")
- [x] Дательный — "кому" ("отправь мне", "помоги команде")
- [x] Творительный — "чем/кем" ("работаю программистом")
- [ ] Case endings for masculine, feminine, neuter nouns
- [ ] Case endings for adjectives (большой → большого → большому...)
- [ ] Case endings for pronouns (я → меня → мне → мной)
- [ ] Plural case endings

### 1.2 Verb Conjugation (Спряжение глаголов) ⬜

**Present tense — 2 conjugation groups:**

| Group | Ending pattern | Example |
|-------|---------------|---------|
| 1st (-ать, -еть) | -ю, -ешь, -ет, -ем, -ете, -ют | работать → работаю, работаешь... |
| 2nd (-ить) | -ю, -ишь, -ит, -им, -ите, -ят | говорить → говорю, говоришь... |

- [ ] 1st conjugation pattern + common verbs
- [ ] 2nd conjugation pattern + common verbs
- [ ] Irregular verbs (хотеть, есть, дать, бежать)
- [ ] Past tense (easy: stem + л/ла/ло/ли)
- [ ] Future tense (буду + infinitive OR perfective form)

### 1.3 Verb Aspect (Вид глагола) ⬜
The hardest topic in Russian. Every verb has two forms:

| Imperfective (несовершенный) | Perfective (совершенный) |
|------------------------------|-------------------------|
| Process, repeated action | One-time completed action |
| делать (to do / to be doing) | сделать (to get done) |
| писать (to write / writing) | написать (to finish writing) |
| исправлять (to be fixing) | исправить (to fix, done) |

- [ ] What is aspect and why it matters
- [ ] Most common verb pairs (делать/сделать, писать/написать, etc.)
- [ ] When to use imperfective (process, habit, repeated)
- [ ] When to use perfective (result, one-time, completed)
- [ ] Perfective in future tense (я напишу = I will write [and finish])
- [ ] Imperfective in future (я буду писать = I will be writing)
- [ ] Common prefixes that create perfective (на-, с-, по-, за-, вы-, пере-)

## Phase 2: Sentence Building (Построение предложений)

### 2.1 Prepositions (Предлоги) ⬜
Each preposition requires a specific case.

| Preposition | Case required | Meaning | Example |
|-------------|--------------|---------|---------|
| в + Accusative | Куда? | into, to | иду **в** офис |
| в + Prepositional | Где? | in, at | работаю **в** офисе |
| на + Accusative | Куда? | onto, to | иду **на** созвон |
| на + Prepositional | Где? | on, at | я **на** созвоне |
| с + Instrumental | | with | работаю **с** командой |
| с + Genitive | | from | ушёл **с** работы |
| к + Dative | | toward, to (person) | подойди **к** тимлиду |
| у + Genitive | | at, possession | **у** меня есть вопрос |
| без + Genitive | | without | **без** багов |
| для + Genitive | | for | задача **для** бэкенда |
| о + Prepositional | | about | поговорим **о** проекте |
| из + Genitive | | from, out of | данные **из** базы |
| по + Dative | | by, according to | задача **по** приоритету |
| за + Accusative | | for (time), behind | сделаю **за** час |
| перед + Instrumental | | before | **перед** релизом |
| после + Genitive | | after | **после** деплоя |

- [ ] в/на + movement (Accusative) vs location (Prepositional)
- [ ] с + Instrumental (with) vs с + Genitive (from)
- [ ] Most common prepositions in work context
- [ ] Practice: forming phrases with prepositions

## Phase 3: Professional Russian (Профессиональный русский)

### 3.1 Work Communication (Рабочее общение) ⬜

**Daily standup phrases:**
- [ ] Что я делал вчера (What I did yesterday)
- [ ] Что буду делать сегодня (What I'll do today)
- [ ] Есть ли блокеры (Any blockers)

**Asking for help:**
- [ ] Можешь посмотреть... (Can you look at...)
- [ ] Не могу разобраться с... (Can't figure out...)
- [ ] У меня вопрос по... (I have a question about...)

**Code review:**
- [ ] Тут лучше сделать так... (Better to do it this way...)
- [ ] Зачем здесь это нужно? (Why is this needed here?)
- [ ] Можно упростить... (Can simplify...)

**Meetings:**
- [ ] Я думаю, что... (I think that...)
- [ ] Я согласен / не согласен (I agree / disagree)
- [ ] Давай обсудим... (Let's discuss...)
- [ ] Мне кажется... (It seems to me...)
- [ ] Правильно ли я понимаю, что...? (Do I understand correctly that...?)

- [ ] Practice: simulate a standup in Russian
- [ ] Practice: simulate a code review discussion
- [ ] Practice: simulate a planning meeting

## Phase 4: Fluency (Свободное владение)

### 4.1 Native-Like Speech Patterns ⬜

- [ ] Particles (же, ли, бы, ведь, вот, ну) — these make you sound natural
- [ ] Colloquial contractions (чё = что, щас = сейчас, комп = компьютер)
- [ ] Filler words (ну, типа, короче, в смысле, как бы)
- [ ] Softening phrases (мне кажется, наверное, скорее всего, по-моему)
- [ ] Idiomatic expressions for dev context

### 4.2 Common Mistakes to Avoid ⬜

- [ ] Gender agreement (этот/эта/это must match noun gender)
- [ ] Aspect choice (делать vs сделать in context)
- [ ] Motion verbs (идти/ходить, ехать/ездить — directional vs habitual)
- [ ] Verbs of position (стоять/лежать/сидеть/висеть)
- [ ] "Свой" vs "мой/его/её" (reflexive possession)

### 4.3 Listening & Speaking Practice ⬜

- [ ] Understand fast native speech
- [ ] Respond without long pauses
- [ ] Use appropriate register (formal vs informal)
- [ ] Handle unexpected questions in meetings
