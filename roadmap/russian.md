# Russian Roadmap

> **L1** = aware & can use · **L2** = deep & efficient · Status: ⬜ not started · 🔄 in progress · ✅ done
> **Notes:** `notes/russian/` (`grammar.md`, `vocabulary.md`, `interview-phrases.md`) · **Practice:** speaking/writing exercises (no code folder)

**Goal:** speak fluently like a native and work with a Russian-speaking dev team. **Mode:** polish, not build from scratch — focus on the weak points: cases, verb aspect, gender agreement. **Daily task:** one word / phrase / grammar point.

**Why (EN):** Many backend teams in the region (Uzbekistan, Russia, CIS companies) work, interview and write documentation in Russian, so grammar mistakes in cases, aspect and gender make a strong engineer sound junior. In the AI era written Russian can be checked by tools, but standups, code-review discussions and live interviews need fast, correct speech of your own.
**Зачем (RU):** Многие backend-команды в регионе (Узбекистан, Россия, СНГ) работают, проводят интервью и пишут документацию на русском, поэтому ошибки в падежах, виде глагола и роде делают сильного инженера похожим на джуна. В эпоху ИИ письменный русский можно проверить инструментами, но стендапы, обсуждения на ревью и живые интервью требуют собственной быстрой и правильной речи.

## RU 1 — Cases (Падежи) 🔥 weak point
The #1 priority. Cases change word endings based on the role in the sentence.

**L1 — aware & can use**
- 🔄 **1.1 Nominative & Accusative** — кто? что? / кого? что?, subject vs direct object, animate vs inanimate accusative (вижу сервер / позови разработчика), "я вижу задачу"
- 🔄 **1.2 Genitive** — кого? чего?, possession (код сервера), negation (нет данных), absence, after numbers (5 серверов), after много/мало/несколько, "of something"
- 🔄 **1.3 Dative** — кому? чему?, to whom / for whom, "отправь мне", "помоги команде", "мне нужно", "мне кажется", "по + dative" (по документации)
- 🔄 **1.4 Instrumental** — кем? чем?, with what / by means of / "as", "работаю программистом", "работать с базой данных", "быть разработчиком", "пользоваться Git-ом"
- 🔄 **1.5 Prepositional** — о ком? о чём? где?, always with a preposition, location and topic, "в офисе", "о проекте", в/на + prepositional (в проекте, на сервере)

**L2 — deep & efficient**
- ⬜ **1.6 Singular noun endings by gender** — masculine (сервер → сервера → серверу), feminine on -а/-я (задача → задачи → задаче), feminine on -ь (память, очередь), neuter (-о/-е: письмо, решение), animate accusative = genitive
- ⬜ **1.7 Plural case endings** — nominative plural (-ы/-и/-а), genitive plural (серверов, задач, решений, данных), dative -ам/-ям, instrumental -ами/-ями, prepositional -ах/-ях
- ⬜ **1.8 Adjective case endings** — большой → большого → большому → большим → о большом, feminine -ой/-ую, soft-stem adjectives (последний), agreement in case with noun

📋 **Reference — 6 cases**

| # | Case | Question | Example | When used |
|---|------|----------|---------|-----------|
| 1 | Именительный (Nominative) | Кто? Что? | Это **программист** | Subject — who/what does the action |
| 2 | Родительный (Genitive) | Кого? Чего? | Нет **программиста** | Possession, absence, "of something" |
| 3 | Дательный (Dative) | Кому? Чему? | Отправь **программисту** | To whom, for whom |
| 4 | Винительный (Accusative) | Кого? Что? | Вижу **программиста** | Direct object — what you act on |
| 5 | Творительный (Instrumental) | Кем? Чем? | Работаю **программистом** | With what, by means of, "as" |
| 6 | Предложный (Prepositional) | О ком? О чём? | Говорю о **программисте** | About, in, at (always with a preposition) |

**Learning order (by usefulness):**
- [x] Именительный — already know (basic form)
- [x] Винительный — most common, direct objects ("я вижу задачу")
- [x] Предложный — location, topic ("в офисе", "о проекте")
- [x] Родительный — "нет чего", possession ("код сервера")
- [x] Дательный — "кому" ("отправь мне", "помоги команде")
- [x] Творительный — "чем/кем" ("работаю программистом")
- [ ] Case endings for masculine, feminine, neuter nouns → 1.6
- [ ] Case endings for adjectives (большой → большого → большому...) → 1.8
- [ ] Case endings for pronouns (я → меня → мне → мной) → 5.1
- [ ] Plural case endings → 1.7

Full ending tables: `notes/russian/grammar.md`.

## RU 3 — Verb aspect (Вид глагола) 🔥 weak point
The hardest topic in Russian. Every verb has two forms.

**L1 — aware & can use**
- ⬜ **3.1 What aspect is & common pairs** — imperfective (несовершенный) vs perfective (совершенный), process vs result, делать/сделать, писать/написать, исправлять/исправить, проверять/проверить, решать/решить
- ⬜ **3.2 When to use imperfective** — process, habit, repeated action, duration, "я делал задачу весь день", "каждый день проверяю", "я делал" (process)
- ⬜ **3.3 When to use perfective** — result, one-time completed action, sequence of actions, "я сделал задачу", "я сделал" (result), "исправил баг и задеплоил"

**L2 — deep & efficient**
- ⬜ **3.4 Aspect in past & future** — "я делал" (process) vs "я сделал" (result), perfective future (я напишу = I will write [and finish]), imperfective future (я буду писать = I will be writing), "буду делать" vs "сделаю"
- ⬜ **3.5 How aspect pairs are formed** — prefixes creating perfective (на-, с-, по-, за-, вы-, пере-), suffixes (-ыва-/-ива-: переписать → переписывать), different stems (брать/взять, говорить/сказать), prefix changes meaning (переделать, доделать)
- ⬜ **3.6 Aspect in imperative, negation & infinitive** — "сделай!" (do it once) vs "делай!" (go ahead / keep doing), "не делай" (prohibition), "не забудь", "надо сделать" vs "не надо делать", aspect after начать/закончить (+ imperfective)

📋 **Reference — aspect pairs**

| Imperfective (несовершенный) | Perfective (совершенный) |
|------------------------------|-------------------------|
| Process, repeated action | One-time completed action |
| делать (to do / to be doing) | сделать (to get done) |
| писать (to write / writing) | написать (to finish writing) |
| исправлять (to be fixing) | исправить (to fix, done) |

- [ ] What is aspect and why it matters → 3.1
- [ ] Most common verb pairs (делать/сделать, писать/написать, etc.) → 3.1
- [ ] When to use imperfective (process, habit, repeated) → 3.2
- [ ] When to use perfective (result, one-time, completed) → 3.3
- [ ] Perfective in future tense (я напишу = I will write [and finish]) → 3.4
- [ ] Imperfective in future (я буду писать = I will be writing) → 3.4
- [ ] Common prefixes that create perfective (на-, с-, по-, за-, вы-, пере-) → 3.5

## RU 6 — Prepositions (Предлоги)
Each preposition requires a specific case.

**L1 — aware & can use**
- ✅ **6.1 в / на: direction vs location** — в/на + accusative (куда? иду в офис, иду на созвон), в/на + prepositional (где? работаю в офисе, я на созвоне), на for events/surfaces
- ✅ **6.2 Common work prepositions** — у + genitive (у меня есть вопрос), к + dative (подойди к тимлиду), для, без, о, из, по, за, перед, после — with correct cases

**L2 — deep & efficient**
- ⬜ **6.3 Double-case prepositions** — с + instrumental (with: работаю с командой) vs с + genitive (from: ушёл с работы), за + accusative (for time: сделаю за час) vs за + instrumental (behind/for: зайду за кофе), по + dative
- ⬜ **6.4 "From" & place exceptions** — из (from inside: данные из базы) vs с (from surface/event: с созвона) vs от (from a person: письмо от тимлида), на работе / на проекте / на сервере vs в компании / в команде
- ⬜ **6.5 Time prepositions** — через (in: через час), назад (ago), за (within / before: за день до релиза), на (for planned duration: на неделю), в + accusative (в понедельник, в 3 часа), до / после / перед

📋 **Reference — prepositions and cases**

| Preposition | Case required | Meaning | Example |
|-------------|--------------|---------|---------|
| в + Accusative | Куда? | into, to | иду **в** офис |
| в + Prepositional | Где? | in, at | работаю **в** офисе |
| на + Accusative | Куда? | onto, to | иду **на** созвон |
| на + Prepositional | Где? | on, at | я **на** созвоне |
| с + Instrumental | | with | работаю **с** командой |
| с + Genitive | | from | ушёл **с** работы |
| к + Dative | | toward, to (person) | подойди **к** тимлиду |
| у + Genitive | | at, possession | **у** меня есть вопрос |
| без + Genitive | | without | **без** багов |
| для + Genitive | | for | задача **для** бэкенда |
| о + Prepositional | | about | поговорим **о** проекте |
| из + Genitive | | from, out of | данные **из** базы |
| по + Dative | | by, according to | задача **по** приоритету |
| за + Accusative | | for (time), behind | сделаю **за** час |
| перед + Instrumental | | before | **перед** релизом |
| после + Genitive | | after | **после** деплоя |

## Common mistakes to avoid
- [ ] Gender agreement (этот/эта/это must match noun gender) → RU 4
- [ ] Aspect choice (делать vs сделать in context) → RU 3
- [ ] Motion verbs (идти/ходить, ехать/ездить — directional vs habitual) → RU 10
- [ ] Verbs of position (стоять/лежать/сидеть/висеть) → RU 10.4
- [ ] "Свой" vs "мой/его/её" (reflexive possession) → RU 5.4

## Known weak points (from earlier sessions)
- Genitive case for possession (сервера, not "в сервере")
- Verb aspect: делать (imperfective, ongoing) vs сделать (perfective, completed)
- Prepositions: в + Prepositional for location, на + Prepositional for surfaces/events
- Gender agreement of adjectives and past-tense verbs
