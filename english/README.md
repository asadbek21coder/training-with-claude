# English Learning Track

## Goal
Improve technical English for software engineering interviews and professional communication.

## Structure

- `vocabulary.md` — Verbs, nouns, collocations, interview phrases (continuously updated)
- `grammar.md` — Common grammar mistakes and corrections
- `interview-phrases.md` — Ready-to-use phrases for behavioral and technical interviews
- `practice.md` — Sentences to practice, corrections from discussions

## How It Works
- Every discussion session: English corrections are tracked in vocabulary.md
- Separate practice: review and use phrases in context
- Focus on: technical vocabulary, professional phrasing, natural-sounding answers
