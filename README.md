# Learning — Senior Software Engineer Path

Go backend engineer → senior. One map, small daily steps.

## Start here
1. **`BIG_PICTURE.md`** — the whole map: every track → topic → subtopic → terms, with status. Pick one piece a day.
2. **`LOG.md`** — one line per day.
3. **`reference/00-senior-engineer-guide.md`** — why each area matters, AI-era priorities, books, capstone project.

## Daily routine
| Block | Time | Track |
|---|---|---|
| Main | 40–50 min | **GO** (current main track) |
| Parallel | 10–20 min | **DSA** — one concept / term / problem |
| Parallel | 5–10 min | **EN** — one term / phrase / grammar point |
| Parallel | 5–10 min | **RU** — one word / phrase / grammar point |

## Structure
```
learning/
├── BIG_PICTURE.md        # complete roadmap with statuses (the one file to look at)
├── LOG.md                # daily log
├── CLAUDE.md             # session rules for Claude
├── reference/            # term dictionaries per area + senior engineer guide
├── notes/<track>/        # discussion notes (EN + RU): go/, dsa/, system-design/, postgres/ ...
├── tasks/<track>/<topic>/# questions.md, tasks.md
├── code/                 # Go module: ds/ (skeletons), ds/ds_imp/ (my implementations), go/ (Go track exercises)
├── interviews/           # quick-reference, weak-points, sessions/, companies/, my-projects.md
├── english/              # PLAN.md (method), vocabulary.md (corrections, terms)
└── russian/              # ROADMAP.md, grammar.md, vocabulary.md, interview_phrases.md
```
