# Learning — Senior Software Engineer Path

Go backend engineer → senior. Every track has the same three parts:

| Part | Where | What |
|---|---|---|
| **Roadmap** | `roadmap/<track>.md` | all topics → subtopics → terms, in **L1** (aware & can use) and **L2** (deep & efficient), with status and a 🛠 practice line per topic |
| **Notes** | `notes/<track>/` | what I learned, written for fast recall (format: `notes/README.md`) |
| **Code** | `code/<track>/` | hands-on practice; every topic folder has a README with instructions |

**Overview of all tracks and progress:** `roadmap/README.md`
**Daily log:** `LOG.md`
**Why each area matters, AI-era priorities, books:** `reference/00-senior-engineer-guide.md`

## Tracks
`golang` (main now) · `algorithms-ds` · `english` · `russian` · `ai` (daily, parallel) · `postgres` · `system-design` · `os` · `linux` · `networking` · `devops` · `common-swe` (auth, hashing, security, API design, Git, career) · `qa` · `design-patterns`
