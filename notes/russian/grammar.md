# Russian Grammar — Cases (Падежи)

## All 6 Cases — Summary Table (Сводная таблица)

| # | Case / Падеж | Question / Вопрос | Use / Когда | Example / Пример |
|---|---|---|---|---|
| 1 | Именительный (Nom.) | Кто? Что? | Subject / Подлежащее | **Сервер** работает |
| 2 | Родительный (Gen.) | Кого? Чего? | Possession, absence, "of" | Нет **доступа**, код **сервера** |
| 3 | Дательный (Dat.) | Кому? Чему? | To whom, for whom | Отправь **тимлиду**, по **задаче** |
| 4 | Винительный (Acc.) | Кого? Что? | Direct object | Вижу **задачу**, позови **тимлида** |
| 5 | Творительный (Instr.) | Кем? Чем? | With, as, by means of | Работаю **программистом**, с **командой** |
| 6 | Предложный (Prep.) | О ком? О чём? Где? | About, location | В **коде**, о **проекте** |

## Masculine Endings (Мужской род)

| Case | Inanimate (неодуш.) | Animate (одуш.) | Example |
|---|---|---|---|
| Именительный | сервер | разработчик | — |
| Родительный | сервер**а** | разработчик**а** | код сервера |
| Дательный | сервер**у** | разработчик**у** | отправь разработчику |
| Винительный | сервер (=Им.) | разработчик**а** (=Род.) | вижу сервер / позови разработчика |
| Творительный | сервер**ом** | разработчик**ом** | перед сервером |
| Предложный | сервер**е** | разработчик**е** | на сервере |

## Common Prepositions + Cases (Предлоги + падежи)

| Preposition | Case required | Meaning | Example |
|---|---|---|---|
| без + Gen. | Родительный | without | без **багов** |
| из + Gen. | Родительный | from | из **базы** |
| у + Gen. | Родительный | at, has | у **тимлида** есть вопрос |
| нет + Gen. | Родительный | there is no | нет **доступа** |
| к + Dat. | Дательный | toward, for | к **релизу** |
| по + Dat. | Дательный | regarding | по **задаче** |
| в + Acc. | Винительный | into (direction) | иду **в** офис |
| на + Acc. | Винительный | onto (direction) | иду **на** созвон |
| с + Instr. | Творительный | with | с **командой** |
| перед + Instr. | Творительный | before | перед **релизом** |
| между + Instr. | Творительный | between | между **сервисами** |
| в + Prep. | Предложный | in (location) | в **коде** |
| на + Prep. | Предложный | on/at (location) | на **созвоне** |
| о + Prep. | Предложный | about | о **проекте** |

## Key Rules to Remember (Запомни)

1. **Accusative masculine**: animate = like Genitive (-а), inanimate = like Nominative (no change)
2. **Prepositional**: almost everything ends in -е, except -ия/-ие words → -и
3. **Genitive feminine**: -а → -и (opposite of Dative -а → -е)
4. **в/на**: + Accusative = direction (куда?), + Prepositional = location (где?)
