# Notes — what I learned, written for fast recall

One folder per track (same names as `roadmap/` and `code/`). One file per topic: `notes/<track>/<NN>-<topic-slug>.md`.
Notes contain both English and Russian.

## Note format (copy for every new topic)

```markdown

Date learned: YYYY-MM-DD · Layer: L1 / L2

## TL;DR (3 lines max)

RU: ...

## Problem → Solution
What problem existed before, and how this solves it.

## Key terms

|---|---|---|

## How it works / how to use
Short explanation + a tiny code example.

## Senior answer (interview-ready)
EN: ...
RU: ...

## Gotchas
- ...

## Recall questions (answer without looking — that's how memory sticks)
1. ...
2. ...

## Links
Practice: `code/<track>/<NN>-.../` · Source: docs / book chapter
```

## How to refresh memory
- Read only the **TL;DR** and try to answer the **Recall questions** first, then check the rest.
- Weekly: pick 3 old notes at random and answer their recall questions (spaced repetition).
