# NeetCode Pro — how to use it (user has a subscription, 2026-11-24)

## What it has (checked 2026-11-24)
- **Courses:** DSA for Beginners, Advanced Algorithms, System Design for Beginners, System Design Interviews, Object-Oriented Design Interviews + OOD Patterns, SQL for Beginners (PostgreSQL), Full Stack Development, Python for interviews, Python OOP.
- **Practice:** 300+ problems in a browser editor with tests; lists Blind 75 / NeetCode 150 / NeetCode 250; 100+ company-tagged sets; progress tracking; solutions in 8 languages **including Go**.
- **AI:** NeetBot chat, AI hints & debug; voice mock interviews (limited per day).

## Where each piece goes in this repo
| NeetCode part | Roadmap | When |
|---|---|---|
| DSA for Beginners videos | DSA 1–16 L1 (finish the 13/49 → 49/49) | **now**, as the daily DSA small piece (1 lesson/day) |
| NeetCode 150 → 250 in **Go**, timed | DSA 21.1–21.3 | light now (2×/week, easy), full after Go L1 |

| SQL for Beginners (PostgreSQL) | PG L1 quick pass | when `postgres` starts — fast, you already know most |
| Full Stack Development | product-engineer frontend gap | later, only if the product track starts |
| Python courses | skip (Go focus); maybe for AI work later | — |

## Rules (so it really trains you)
1. **Solve in Go**, the language you interview in and teach.
2. **Timed attempts: no NeetBot, no AI hints.** Hints/NeetBot only *after* the timer ends or after 20 min stuck — then log it as 💡 in `code/algorithms-ds/practice-log.md`.
3. Watch the solution video **after** your attempt, never before.
4. Re-solve 💡/❌ problems after 3, 7, 21 days (DSA 21.5).
5. Courses = the "learn" part of a daily card; problems = the "practice" part.
