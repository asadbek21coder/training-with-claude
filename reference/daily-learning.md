# Daily learning — format and resources

The user wants **something useful every day** (watch / read / practice), not big tracks. The roadmap stays the map; this file is the daily routine.

## Daily card (45–60 min)
1. **Learn (15–20 min):** one short video or reading from the list below, tied to one roadmap ID.
2. **Practice (15–20 min):** commands or code on your own laptop — see it with your own eyes.
3. **Small piece (10 min):** rotate Go · DSA · AI · English/Russian.
4. **Recall (5 min):** write 3 sentences in your own words into `notes/<track>/`.

Rotation of the main piece (one per day): **networking** (most days) → Go → OPS 22 lab → system design → networking …
When a work task needs something (deploy, CI, DNS), that task *is* the day's practice.

## Resources (free unless marked)
